# NYC Living — Lifestyle Blog 🗽

A lifestyle and culture blog website themed around New York City living — covering local spots, culture, style, and city life. Built as a front-end design exercise.

## Stack

| | |
|---|---|
| Framework | React + TypeScript |
| Styling | Tailwind CSS + shadcn/ui |
| Build | Vite |

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
